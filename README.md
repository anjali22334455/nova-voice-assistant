🎙️ AI Voice Assistant
An AI-powered Voice Assistant built with the MERN Stack and Google Gemini AI.

The application allows users to interact with an AI assistant using voice commands or text input. It understands user queries, generates intelligent responses using Google Gemini AI, and speaks the responses back with speech synthesis, providing a seamless conversational experience.

✨ Features
🎤 Voice Input Support
🤖 AI-Powered Responses using Google Gemini AI
⚡ Real-Time AI Conversation
🧠 Context-Aware Responses
📱 Responsive User Interface
🔐 JWT Authentication
🍪 Secure Cookie-Based Login

⚙️ Installation
Clone Repository
git clone https://github.com/DeveloperSharad2004/Ai-Voice-Assistant.git
Install Dependencies
Backend
cd Backend
npm install
Frontend
cd Frontend
npm install
🔑 Environment Variables
Create a .env file inside the Backend folder.

PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

GEMINI_API_KEY=your_google_gemini_api_key

IMAGEKIT_PUBLIC_KEY=your_public_key

IMAGEKIT_PRIVATE_KEY=your_private_key

IMAGEKIT_URL_ENDPOINT=your_url_endpoint
▶️ Run the Project
Backend
npm run dev
Frontend
npm run dev
